# MediCard — Health Cashless Hospitalization & Settlement Platform

Business case **BC-AINE-017** (Insurance — Health Cashless). MediCard is a multi-party platform
for customers, network hospitals, insurer adjudicators and insurer admins. It covers eligibility
lookup, rule-driven pre-authorization, admission tracking, final-bill validation, settlement with
a stubbed payout, and an immutable audit trail.

All production code, tests and migrations were generated by Claude Code agents on the
**Claude Harness Engine** (`.claude/`), extended with a MediCard substrate (agents, skills, hooks,
commands, plugin, MCP). See [AGENTS.md](AGENTS.md) for the map and
[docs/business-case.md](docs/business-case.md) for the context.

> All data is synthetic. No real or confidential data is used anywhere.

## Quick start

Prerequisites: Python ≥ 3.12, Node ≥ 20, Poetry ≥ 2.

```bash
./init.sh          # single command: poetry install + npm ci + build the UI + start on http://localhost:8000
```

Or step by step:

```bash
poetry install
(cd frontend && npm ci && npm run build)
poetry run medicard            # API + portal on http://localhost:8000, seeded on first start
```

> **Windows with a non-ASCII project path** (for example `…\ドキュメント\…`): `poetry install`
> can fail with `'charmap' codec can't encode` when it writes the editable `.pth` file. Run
> `pip install --no-deps -e .` inside the Poetry venv once, then `poetry run medicard` works. See
> `docs/post-mortems/PM-001-environment-first-debugging.md`, incident 6.

Health: `GET http://localhost:8000/health` returns `{"status":"ok"}` (NFR-07). OpenAPI docs are at
`/docs`. The SQLite database is created at `data/medicard.db`. Delete the file to re-seed.

## Quality gates

```bash
poetry run pytest --cov=src --cov-report=xml   # unit + API + architecture tests, writes coverage.xml
poetry run lint-imports                        # import-linter layer contracts
poetry run mypy src && poetry run ruff check .
poetry run python scripts/ac_trace.py          # every AC-NN has tagged tests
bash scripts/test-hooks.sh                     # guardrail hooks behave as specified
cd frontend && npx playwright test             # UI journeys + snapshots (starts its own backend)
```
