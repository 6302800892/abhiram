# MediCard — Cashless Hospitalization & Settlement Platform

BC-AINE-017. A multi-party platform (customer · network hospital · insurer adjudicator · insurer
admin) for eligibility, pre-auth, admission, final bill, settlement and audit. Built on the Claude
Harness Engine. **All production code, tests and migrations are generated by Claude Code agents.**

## Non-Negotiable Rules

1. **No hand-coding.** Humans edit only specs, CLAUDE.md files, agents, skills, hooks, commands.
2. **Spec-Is-Truth.** `specs/app_spec.md` + `specs/*_spec.md` win over code. Change the spec, then regenerate.
3. **PR-only merges.** Never commit to `main`. Branch `<type>/<desc>` → agent review → `git merge --no-ff`.
4. **Synthetic data only.** Seed data in `seed/` is fictional.
5. **Money is `Decimal`** (NFR-01). **PHI never logged** (NFR-03). **Append-only** decisions, bills,
   settlements, audit, migrations (NFR-02/05). **Role check on every route** (NFR-04).

## Quick Reference

**Backend:** `poetry install` · `poetry run pytest` · `poetry run ruff check .` · `poetry run lint-imports` · `poetry run mypy src`
**Frontend:** `cd frontend && npm ci && npm run build` · `npx playwright test`
**Run:** `./init.sh` (install + build + start), or `poetry run medicard` → http://localhost:8000

## Architecture

Strict layers `domain → config → repository → service → api → ui` with one-way imports only.
Enforced by import-linter (`pyproject.toml`), the harness `check-architecture` hook, and
`tests/architecture/`. Details: `docs/architecture.md`, `.claude/architecture.md`.

## Pipeline Commands

Harness: `/brd` `/spec` `/design` `/build` `/auto` `/implement` `/evaluate` `/review` `/test` `/fix-issue`
Project: `/ac-trace` (AC → test map), `/settlement-audit` (money invariants), `/sprint-pr` (gates + no-ff merge)

## Code Style

- TDD mandatory: AC-tagged failing test first (`@pytest.mark.ac("AC-NN")`), then code, then refactor.
- Coverage floor 80 %. Functions < 50 lines, files < 300 lines. Type hints everywhere.
- Errors are typed domain exceptions mapped to `{"error":{"code","message"}}` at the API layer.

## Git

Branch: `<type>/<description>` (e.g. `feat/sprint-2-preauth`). Conventional commits
(`feat:`, `fix:`, `test:`, `refactor:`, `docs:`, `chore:`). Merge: `git merge --no-ff` only.
