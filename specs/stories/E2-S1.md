## User Story
As a network hospital, I want to submit a pre-auth with diagnosis, estimate and admission date so that treatment can be authorised.

## Description
Implements AC-03 as specified in specs/preauth_spec.md, specs/adjudication_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Submission returns 201 and the first decision is PENDING / PA-SUBMITTED.
- A claim case is created in PRE_AUTH.
- Non-positive estimate or past admission date returns 422.
- Ineligible member returns 422 NOT_ELIGIBLE.
