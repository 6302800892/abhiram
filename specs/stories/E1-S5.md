## User Story
As an insurer admin, I want to maintain the network and publish coverage rule versions so that rules change without rewriting history.

## Description
Implements NFR-05 as specified in specs/eligibility_spec.md, specs/network_admin_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Admin can create a hospital and toggle in_network.
- Publishing coverage rules creates version n+1 and leaves version n unchanged.
- Overlapping auto-approved and excluded lists return 422 INVALID_COVERAGE_RULE.
- Direct UPDATE on coverage_rule_versions aborts with append-only.
