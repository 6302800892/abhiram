## User Story
As an insurer, I want a strict case state machine so that no claim skips a step.

## Description
Implements AC-08 as specified in specs/admission_spec.md, specs/settlement_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Happy path PRE_AUTH->ADMITTED->DISCHARGED->SETTLED->CLOSED succeeds.
- DISCHARGED->DISPUTED->CLOSED succeeds.
- Every disallowed transition raises InvalidClaimStateException (409 INVALID_CLAIM_STATE).
- Admitting with a non-approved pre-auth returns 422 PREAUTH_NOT_APPROVED.
