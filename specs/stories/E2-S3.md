## User Story
As an insurer adjudicator, I want a queue of pending pre-auths and a decision form with reason codes so that large or unusual cases get human review.

## Description
Implements AC-04 as specified in specs/preauth_spec.md, specs/adjudication_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Queue lists PENDING pre-auths oldest first.
- Approve, partially approve, reject and raise query each append a decision with reason codes.
- Reason code outside the rule-version catalogue returns 422 UNKNOWN_REASON_CODE.
- Deciding an already decided pre-auth returns 409 INVALID_PREAUTH_STATE.
