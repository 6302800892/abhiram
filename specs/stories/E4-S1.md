## User Story
As an insurer admin, I want to override an auto-rejection with a reason so that edge cases get fair treatment with a full audit trail.

## Description
Implements AC-10 as specified in specs/adjudication_spec.md, specs/reports_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Override of auto-rejected pre-auth appends PA-OVERRIDE and an audit record with actor and timestamp.
- Override of QUERY_RAISED pre-auth is allowed.
- Non-admin override returns 403 and blank reason returns 422; neither writes audit.
- Override of a manually rejected or approved pre-auth returns 422 OVERRIDE_NOT_ALLOWED.
