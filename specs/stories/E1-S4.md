## User Story
As a network hospital, I want to check eligibility by member_id and policy so that I can admit cashless with confidence.

## Description
Implements AC-02 as specified in specs/eligibility_spec.md, specs/network_admin_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Active, in-period, in-network member returns ELIGIBLE with ELG-OK.
- Unknown policy returns NOT_ELIGIBLE with ELG-POLICY-NOT-FOUND.
- Lapsed policy returns both ELG-POLICY-INACTIVE and ELG-OUTSIDE-COVER-PERIOD.
- Out-of-network hospital returns ELG-HOSPITAL-NOT-NETWORK and customer token returns 403.
