## User Story
As a platform operator, I want a health endpoint, structured logs, role-based login and append-only migrations so that every later story builds on a safe base.

## Description
Implements NFR-04, NFR-05, NFR-06, NFR-07 as specified in specs/eligibility_spec.md, specs/network_admin_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- GET /health returns 200 within 1 second of startup.
- POST /api/auth/login returns a bearer token for seeded users and 401 for a wrong password.
- Every response carries an X-Correlation-ID header and every log line is JSON with correlation_id.
- Migrations apply in order and an edited applied migration raises MigrationTamperedError.
