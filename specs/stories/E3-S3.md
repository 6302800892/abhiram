## User Story
As an insurer adjudicator, I want a correct settlement with stub payment so that the hospital is paid the right amount.

## Description
Implements AC-07 as specified in specs/admission_spec.md, specs/settlement_spec.md. The feature spec is the source of truth; this story is the unit of work for one generator teammate.

## Acceptance Criteria
- Settlement = min(final_bill, cap) - deductible - co-pay in Decimal.
- Settlement is never negative and float inputs raise TypeError.
- Settling returns a PAYSTUB- payment reference and reduces remaining sum insured.
- Settling twice returns 409 CASE_SETTLED_IMMUTABLE.
